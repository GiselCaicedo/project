ESTRUCTURA DE COTIZACIONES - ANÁLISIS COMPLETO
==============================================

1. MODELOS PRISMA (Base de Datos)
=================================

MODELO PRINCIPAL: quote
├── id (UUID) - Identificador único
├── client_id (UUID) - Referencia al cliente
├── description (VarChar) - Descripción/referencia
├── value (VarChar) - Valor total en string
├── url (VarChar) - URL del PDF
├── created (Timestamptz) - Fecha de creación
├── updated (Timestamptz) - Fecha de actualización
├── status (Boolean?) - null=pendiente, true=aprobada, false=rechazada
└── Relaciones:
    ├── client (relación N:1)
    ├── quote_detail[] (relación 1:N)
    └── quote_attachment[] (relación 1:N)

MODELO: quote_detail (Detalles de la cotización)
├── id (UUID)
├── quote_id (UUID) - FK a quote
├── service_id (UUID) - FK a service
├── item (Int) - Número de item
├── quantity (Int) - Cantidad
├── total_value (Float) - Valor total del item
├── created (Timestamptz)
├── updated (Timestamptz)
├── status (Boolean?) - Estado del item
└── Relaciones:
    ├── quote (relación N:1)
    └── service (relación N:1)

MODELO: quote_attachment (Relación cotización-factura)
├── id (UUID)
├── quote_id (UUID) - FK a quote
├── invoice_id (UUID) - FK a invoice
└── Relaciones:
    ├── quote (relación N:1)
    └── invoice (relación N:1)

MODELO: service (Servicios disponibles)
├── id (UUID)
├── service_category_id (UUID)
├── name (VarChar)
├── unit (VarChar)
├── description (Text)
├── price (Decimal 12,2)
├── frequency (VarChar)
├── start_date (Timestamptz)
├── end_date (Timestamptz)
├── tax_one_id (UUID) - Primer impuesto
├── tax_two_id (UUID) - Segundo impuesto
├── subtotal (Decimal 12,2)
├── created (Timestamptz)
├── updated (Timestamptz)
├── status (Boolean)
└── Relaciones:
    ├── quote_detail[] (1:N)
    ├── invoice_detail[] (1:N)
    ├── service_category (N:1)
    ├── tax_one (N:1)
    └── tax_two (N:1)

MODELO: tax (Impuestos)
├── id (UUID)
├── name (VarChar)
├── description (VarChar)
├── percentage (Decimal 5,2)
├── active (Boolean)
├── created (Timestamptz)
└── updated (Timestamptz)

MODELO: invoice (Facturas relacionadas)
├── id (UUID)
├── client_id (UUID)
├── service_id (UUID)
├── description (VarChar)
├── value (VarChar)
├── url (VarChar)
├── subtotal (Decimal 12,2)
├── tax_one (Decimal 12,2)
├── tax_two (Decimal 12,2)
├── include_iva (Boolean)
├── total (Decimal 12,2)
├── created (Timestamptz)
├── updated (Timestamptz)
├── status (Boolean)
├── expiry (Timestamptz)
└── Relaciones:
    ├── quote_attachment[] (1:N)
    ├── invoice_detail[] (1:N)
    ├── client (N:1)
    └── service (N:1)

2. ENDPOINTS API
================

ADMIN ROUTES (/api/v1/admin/quotes)
─────────────────────────────────────
GET    /                    → listQuotesCtrl        [Lista todas las cotizaciones]
POST   /                    → createQuoteCtrl       [Crea nueva cotización]
GET    /:id                 → getQuoteByIdCtrl      [Obtiene detalle de cotización]
PUT    /:id                 → updateQuoteCtrl       [Actualiza cotización]
DELETE /:id                 → deleteQuoteCtrl       [Elimina cotización]
POST   /:id/pdf             → generateQuotePdfCtrl  [Genera PDF]
POST   /:id/email           → sendQuoteEmailCtrl    [Envía por email]
POST   /:id/invoice         → convertQuoteToInvoiceCtrl [Convierte a factura]

CLIENT ROUTES (/api/v1/client/quotes)
──────────────────────────────────────
GET    /                    → listClientQuotesCtrl       [Lista cotizaciones del cliente]
POST   /                    → createClientQuoteCtrl      [Cliente crea cotización]
GET    /:id                 → getClientQuoteDetailCtrl   [Detalle de cotización]
POST   /:id/generate-invoice → generateInvoiceFromQuoteCtrl [Genera factura desde cotización]

3. SERVICIOS BACKEND
====================

ADMIN QUOTE SERVICE (/backend/src/modules/admin/services/quoteService.ts)
──────────────────────────────────────────────────────────────────────────
✓ listQuotes()                      → Obtiene todas las cotizaciones con detalles
✓ createQuote(payload)              → Crea nueva cotización con servicios
✓ getQuoteById(id)                  → Obtiene cotización con acciones disponibles

✓ convertQuoteToInvoice(id)         → Convierte cotización a factura (transaccional)
✓ updateQuote(id, payload)          → Actualiza cotización (con auto-facturación si se aprueba)
✓ deleteQuote(id)                   → Elimina cotización (solo si no tiene factura)

Características:

- Cálculo automático de totales

9. FLUJO DE CONVERSIÓN COTIZACIÓN → FACTURA
=============================================

Escenario 1: Admin aprueba cotización
─────────────────────────────────────
1. Admin actualiza quote.status = true (aprobada)
2. Sistema detecta que no tiene factura
3. Crea automáticamente:
   - invoice (con datos de quote)
   - invoice_detail (desde quote_detail)
   - quote_attachment (vinculación)
4. Quote actualizado con updated timestamp

Escenario 2: Admin convierte manualmente
────────────────────────────────────────
1. Admin presiona "Convertir a factura"
2. Sistema valida que no tenga factura
3. Si ya existe, retorna ID existente
4. Si no existe, realiza mismo proceso que Escenario 1
5. Retorna invoiceId con resultado

Escenario 3: Cliente genera factura
───────────────────────────────────
1. Cliente obtiene cotización
2. Cliente presiona "Generar factura"
3. Sistema valida acceso (cliente_id)
4. Crea invoice y detalles
5. Crea quote_attachment
